# Security Policy

## Scope

This repository contains documentation and Python scripts. There is no production service, authentication system, or user data involved.

## Reporting a vulnerability

If you discover a security issue in the scripts (e.g., path traversal in file parsing, unsafe deserialization), please open a GitHub issue labeled `security`. For sensitive issues, contact the maintainers directly via the email listed on the GitHub profile.

## Supported versions

Only the current `main` branch is actively maintained.
